# 🛡️ CyberShield - كن درعك الرقمي

منصة تعليمية تفاعلية للأمن السيبراني وحماية البيانات الشخصية للأطفال والمراهقين من سن 12 إلى 18 سنة.

## 🌟 المميزات

- 📚 دروس تعليمية تفاعلية عن الأمن السيبراني
- 🧠 اختبارات تفاعلية لقياس المعرفة
- 🎮 نظام نقاط وميداليات
- 👨‍💼 لوحة تحكم للمديرين
- 🔒 حماية متقدمة باستخدام bcrypt و Helmet
- 🎨 تصميم جذاب بألوان سيبرانية (أزرق داكن × نيون أخضر)

## 🚀 التثبيت والتشغيل

### المتطلبات
- Node.js (الإصدار 14 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. تثبيت المكتبات المطلوبة:
```bash
npm install
```

2. تشغيل السيرفر:
```bash
npm start
```

أو للتطوير مع إعادة التشغيل التلقائي:
```bash
npm run dev
```

3. افتح المتصفح على:
```
http://localhost:3000
```

## 📁 هيكل المشروع

```
CyberShield/
├── data/              # ملفات JSON للبيانات
│   ├── users.json     # بيانات المستخدمين
│   ├── lessons.json   # الدروس التعليمية
│   ├── quiz.json      # أسئلة الاختبارات
│   └── scores.json    # نتائج الاختبارات
├── public/            # الملفات العامة
│   ├── css/          # ملفات CSS
│   ├── js/           # ملفات JavaScript
│   └── *.html        # صفحات HTML
├── server.js         # سيرفر Express
└── package.json      # ملف التبعيات
```

## 🎯 الصفحات الرئيسية

- **الصفحة الرئيسية** (`/`) - مقدمة عن المنصة
- **تسجيل الدخول** (`/login`) - تسجيل الدخول للمستخدمين
- **إنشاء حساب** (`/register`) - إنشاء حساب جديد
- **الدروس** (`/lessons`) - عرض الدروس التعليمية
- **الاختبارات** (`/quiz`) - اختبارات تفاعلية
- **لوحة التحكم** (`/admin`) - إدارة الدروس والأسئلة (للمديرين فقط)

## 🔐 الحساب الافتراضي للمدير

لإنشاء حساب مدير، يمكنك تعديل ملف `data/users.json` يدوياً أو استخدام واجهة إنشاء الحساب ثم تعديل الحساب في الملف.

## 🛠️ التقنيات المستخدمة

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: Node.js, Express.js
- **Security**: bcryptjs, Helmet.js
- **Database**: JSON Files
- **Styling**: Custom CSS with animations
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Cairo)
